# Fitapp

App web personal adaptable a celulares. Requiere Node.js 20 o posterior, sin dependencias externas.

## Desarrollo

Desde el directorio del repositorio:

```sh
npm run check
npm run dev
```

El servidor usa el puerto 3000 o la variable `PORT`.

## Primera versión

- Plan inicial de cuatro sesiones de gimnasio, adaptable a dos o tres.
- Ejercicios completados, cargas e historial de sesiones.
- Pasos diarios manuales y comidas con calorías ingresadas manualmente.
- Datos locales en el navegador: no se sincronizan ni constituyen una copia de seguridad.

Pendientes: integración con Health Connect y análisis de comidas mediante fotos. No se requieren credenciales para esta versión. La rutina es una propuesta inicial para ajustar según la respuesta al entrenamiento.
